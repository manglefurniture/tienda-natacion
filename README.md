# Tienda Natación

Tienda pública independiente de Hache Natación.

## Producción

https://tienda.hnatacion.com

## Arquitectura inicial

- Frontend público servido desde `public/`.
- Lógica de aplicación en `src/`.
- Configuración local mediante variables de entorno.
- Base de datos MariaDB independiente: `hache_tienda`.
- Integración de pagos prevista con Mercado Pago.

## Estado

Proyecto en fase inicial. La infraestructura DNS, HTTPS y Nginx se mantiene separada del sistema principal de Hache Natación.
